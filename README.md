# Scale My Publication - Publications

WordPress plugin foundation for publication management inside Scale My Publication systems.

## Current State

- Version: `0.1.1`
- Namespace: `smp_publications`
- WordPress folder slug: `scale-my-publication-publications`
- Settings page slug: `smp-publications`
- GitHub repository: `mikeyperes/scale-my-publication-publications`

This first release intentionally ships as a lightweight "Hello World" bootstrap with an HWS-style GitHub updater and admin settings page.

## Planned Structure

- `src/Admin`: dashboard screens and admin workflows.
- `src/Content`: publication post types, taxonomies, and metadata.
- `src/Integrations`: bridge code for HWS Base Tools, SFPF/verified profiles, Hexa PR Wire, and related systems.
- `src/Support`: shared helpers and runtime utilities.
